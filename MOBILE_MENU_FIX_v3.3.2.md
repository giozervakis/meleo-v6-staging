# MELEO v3.3.2 — Mobile navigation hotfix

- Το mobile drawer μεταφέρθηκε έξω από το sticky `.topbar`, ώστε το Firefox `backdrop-filter` να μην περιορίζει το `position: fixed` overlay στο ύψος του header.
- Full-height `100dvh` drawer με safe-area support και εσωτερικό scrolling.
- Πλήρες menu με Αρχική, Αναζήτηση, Smart Request, MELEO Now, Συνδρομές και Για επαγγελματίες.
- Role-aware account action για Patient / Professional / Admin.
- Body scroll lock και κλείσιμο με Escape / tap έξω / X / navigation.
- Μεγαλύτερα touch targets και mobile-friendly descriptions.

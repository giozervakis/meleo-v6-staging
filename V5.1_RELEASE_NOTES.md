# MELEO v5.1 — Production Infrastructure

## Implemented

- 3 ανεξάρτητα Node application instances (`app1`, `app2`, `app3`).
- nginx `least_conn` load balancing με upstream failover.
- SSE-safe nginx route για `/api/live` χωρίς buffering.
- Redis 7.4 service με AOF persistence και password authentication.
- Redis-backed distributed rate limiting, atomic μέσω Lua.
- PostgreSQL automatic fallback αν υπάρξει προσωρινή βλάβη Redis.
- Redis hot cache για geocoding με durable PostgreSQL fallback.
- Redis readiness check στο `/api/ready`.
- Instance identification στο `/api/health` για verification του load balancing.
- Production DB pool default 8 ανά node.
- Containers με `no-new-privileges`; application root filesystem read-only και writable upload volume/tmpfs.
- Updated TLS nginx config και production deployment guide.
- Development Docker stack εμπλουτισμένο με Redis.

## Deliberately not included yet

- S3-compatible verification document storage.
- Background email/job queue.
- Sentry/OpenTelemetry observability.
- Frontend `App.tsx` decomposition/code splitting.
- PostgreSQL read replica / PostGIS — θα προστεθούν μόνο εφόσον metrics αποδείξουν ανάγκη.

## Compatibility

Δεν αλλάζει το relational schema της v5.0. Δεν απαιτείται data migration για upgrade από v5.0 σε v5.1.

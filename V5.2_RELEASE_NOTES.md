# MELEO v5.2 — Background Jobs & Observability

## Implemented
- PostgreSQL-backed background job queue with `FOR UPDATE SKIP LOCKED`.
- Dedicated worker container with configurable concurrency.
- Transactional emails are queued instead of blocking HTTP requests.
- Exponential retries and terminal `failed` dead-letter status.
- Recovery of stale worker locks after crashes/restarts.
- Structured JSON logs with request IDs.
- Slow-request logging and HTTP status-family counters.
- Protected Prometheus-compatible `/api/metrics` endpoint.
- Queue-depth and PostgreSQL pool metrics.
- Migration runner now executes every numbered SQL migration in order.

## Next production milestone
S3-compatible encrypted object storage for verification documents, then automated E2E/load validation.

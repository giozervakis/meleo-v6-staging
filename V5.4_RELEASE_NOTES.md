# MELEO v5.4 — Frontend Refactor & Code Splitting

## Στόχος
Η v5.4 μειώνει τον κώδικα που πρέπει να φορτωθεί στην αρχική επίσκεψη, χωρίς αλλαγή στο API, στο PostgreSQL schema ή στα production infrastructure features των v5.1–v5.3.

## Υλοποίηση
- Route-level lazy loading με React `lazy()` + `Suspense`.
- Ξεχωριστό lazy chunk για Admin Control Center.
- Ξεχωριστό lazy chunk για Professional Dashboard / onboarding / verification / subscription tools.
- Ξεχωριστό lazy chunk για Notifications + Help Center.
- Lazy loading των Account Settings και Legal pages από το υπάρχον `Account.tsx`.
- Route loading fallback για ομαλή μετάβαση σε αργότερα-loaded chunks.
- Το `App.tsx` μειώθηκε από περίπου 148 KB source σε περίπου 83 KB source.
- Καμία αλλαγή στο backend API contract ή στο relational schema.

## Αρχεία
- `src/features/admin/AdminPage.tsx`
- `src/features/professional/ProfessionalDashboard.tsx`
- `src/features/support/SupportPages.tsx`
- `scripts/frontend-architecture-check.mjs`

## Validation
Τρέξε:

```bash
npm run frontend-architecture-check
npm run typecheck
npm run build
```

Το production build πρέπει να εμφανίζει περισσότερα από ένα JS chunks στο `dist/assets`.

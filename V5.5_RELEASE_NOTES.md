# MELEO v5.5 — Automated E2E & Load Testing

Το v5.5 μετατρέπει την αξιολόγηση της κλιμάκωσης από θεωρητική σε μετρήσιμη.

## Νέα εργαλεία
- `npm run e2e`: κρίσιμα end-to-end API/session flows με πραγματικά demo roles και JSON report.
- `npm run e2e:browser`: προαιρετικά Playwright browser tests για patient/professional/admin/public routes.
- `npm run loadtest`: duration-based mixed-traffic load test με concurrency, RPS, p50/p95/p99, error rate και threshold gates.
- `npm run loadtest:stages`: διαδοχικά stress stages (default 10,25,50,100 concurrent workers).
- Reports στο `reports/` για σύγκριση releases.

## Default performance gates
- p95 <= 500 ms
- error rate <= 1%
- RPS >= 10 για το baseline test

Όλα είναι παραμετροποιήσιμα μέσω environment variables.

# MELEO v5.6 — Security Hardening + CI/CD

- Admin-specific rate limits και optional IP allowlist.
- Per-account + per-IP login throttling.
- Default admin session TTL 8 ώρες και User-Agent session binding.
- Session inventory / revoke all other sessions.
- Security-event audit logging για failed admin authentication, TOTP replay και denied admin IP.
- Secret scanner + npm dependency audit.
- GitHub Actions quality gate: typecheck, build, architecture/security checks, Docker build, PostgreSQL+Redis E2E και baseline load test.
- Production app containers διατηρούν non-root/read-only/no-new-privileges και πλέον drop all Linux capabilities.

Εκτός v5.6: independent pentest, DPIA/νομικά, live Stripe/TLS και πραγματικό backup/restore drill — αυτά περνούν στο v5.7 Release Candidate.

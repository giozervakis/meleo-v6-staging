# MELEO v5.7 — Production Release Candidate

## Νέα release gates
- `release:preflight`: production environment validation + evidence report.
- `release:tls`: πραγματικός TLS/domain/health έλεγχος.
- `release:stripe`: Stripe API, prices και webhook endpoint readiness.
- `backup:db`: timestamped PostgreSQL custom-format backup.
- `restore:drill`: προστατευμένο restore σε disposable DB μόνο.
- `release:go-no-go`: evidence-based τελική απόφαση GO/NO-GO.
- `v57-check`: static validation της δομής v5.7.

## Safety
Το restore drill απαιτεί `ALLOW_RESTORE_DRILL=YES` και απορρίπτει target URL ίδιο με το production `DATABASE_URL`.

## Scope
Δεν αλλάζει business schema, public API ή frontend behavior. Είναι release-readiness layer πάνω στη v5.6.

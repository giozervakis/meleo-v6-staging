# RC3-D6A - Auth and password security i18n

RC3-D6A starts the D6 localization series with authentication and account security.

## Scope

- Login, registration and forgot-password UI.
- Google OAuth status and fallback feedback.
- Patient/professional role selection.
- Password checklist and strength meter.
- Password visibility accessibility labels.
- 2FA and consent copy.
- Reset-password validation, feedback and session-security notice.
- Greek and English auth translation namespace.
- Dedicated D6A self-test and CI gate integration.

## Validation

- D5Z regression self-test
- D6A self-test
- TypeScript typecheck
- Vite production build
- Full CI gate
- git diff --check

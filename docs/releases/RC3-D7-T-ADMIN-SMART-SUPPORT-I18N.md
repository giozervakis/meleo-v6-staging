# RC3-D7T - Admin Smart Requests + Support i18n

Larger, function-scoped localization tranche covering:
- Smart Requests load/error feedback
- learning prompts and status feedback
- Smart Requests KPI cards
- search, refresh, occurrence labels and timestamps
- Smart Request actions and empty state
- Customer Support title/subtitle/open count
- support reply feedback, localized timestamps, reply input and empty state

All replacements are confined structurally to AdminSmartRequests and AdminSupport.
The D7A baseline remains immutable.

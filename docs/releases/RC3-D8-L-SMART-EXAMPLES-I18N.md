# RC3-D8L - Smart Examples i18n

Removed three duplicated Greek literals from the Smart Search
example buttons.

The same i18n keys now drive both:
- the visible example label
- the text inserted into the Smart Search textarea

This ensures that an English-language user receives English example
text when selecting an example.

No intent dictionaries, catalog values, emergency detection phrases,
or specialty domain values were modified.

RC3-D7A baseline remains immutable.
